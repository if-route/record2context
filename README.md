# record2context

ส่วนขยาย (extension) ของ Google Chrome ที่บันทึกสิ่งที่คุณทำหรือเจอบนหน้าเว็บจริง แล้วเก็บเป็น "บริบท" ที่ AI อ่านเข้าใจได้ทันที ทั้งวิดีโอ ลำดับการกระทำ (คลิก พิมพ์ กดปุ่ม เปลี่ยนหน้า) คำขอ network ข้อผิดพลาดใน console และจุดที่คุณกด **Mark** พร้อมโน้ตและรูปที่วาดชี้ไว้

ใช้ได้ทั้ง tester และ developer เช่น ส่งบั๊กให้ AI ช่วยหาสาเหตุ ให้ AI เขียนขั้นตอนทำซ้ำหรือเขียนเทส ถามเรื่อง flow ของหน้าเว็บ หรือแนบประกอบ issue

- ไม่บอก AI ว่าต้องทำอะไร: บันทึกและชี้ให้ดูเท่านั้น คำถามหรือคำสั่งคุณเขียนเอง
- ไม่มี server ไม่ส่งข้อมูลออกนอกเครื่อง จนกว่าคุณจะคัดลอกหรือแนบไฟล์ไปเอง

## ติดตั้ง: ให้ AI ของคุณทำให้

บอก AI agent ที่เข้าถึงเครื่องของคุณได้ (เช่น Claude Code, Codex, Cursor) ว่า

> ติดตั้ง record2context ตามไฟล์ `<โฟลเดอร์ของ repo นี้>/INSTALL-FOR-AI.md`

AI จะถามคุณเรื่องเดียว คือจะเก็บไฟล์บันทึกไว้ที่โฟลเดอร์ไหน (ถ้าไม่ระบุ ใช้ `~/record2context-recordings`) จากนั้นจะ build ตัว extension ติดตั้งโปรแกรมช่วยบันทึกไฟล์ (helper) แล้วให้ AI อีกตัวตรวจซ้ำจนพร้อมใช้งานจริง

**สิ่งที่คุณต้องทำเองใน Chrome (ครั้งเดียว)** เพราะ Chrome สงวนไว้ให้คนกดเท่านั้น

1. เปิด `chrome://extensions` แล้วเปิด **Developer mode** (มุมขวาบน)
2. ถ้ามี QA Recorder หรือ record2context ตัวเก่าอยู่แล้ว: ถ้าโหลดจากโฟลเดอร์ `dist` ของ repo นี้ แค่กดปุ่ม reload (ลูกศรวน) ก็พอ บันทึกเดิมยังอยู่ แล้วข้ามไปข้อ 4 ถ้าโหลดจากโฟลเดอร์อื่น ให้ลบออกก่อน
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `dist` ใน repo นี้ (AI จะบอก path เต็มให้)
4. ถ้า macOS ถามว่าให้ Google Chrome เข้าถึงไฟล์ในโฟลเดอร์ไหม ให้กด **อนุญาต**
5. คลิกไอคอน record2context หนึ่งครั้ง (ปักหมุดไว้จากไอคอนรูปจิ๊กซอว์ข้างแถบที่อยู่)

ไม่ต้องตอบกลับ AI: มันจะเห็นเองเมื่อ Chrome เริ่มทำงานกับ extension แล้ว ถ้ามีอะไรสงสัยระหว่างติดตั้ง ถาม AI ได้เลย

ต้องมี Node.js 20 ขึ้นไป และ Google Chrome (ทดสอบแล้วบน macOS) โปรแกรม helper จะใช้ Node ตัวที่ใช้ติดตั้งเสมอ ถ้าภายหลังลบ Node เวอร์ชันนั้นออก ต้องให้ AI ติดตั้งใหม่

## วิธีใช้

1. เปิดหน้าเว็บที่จะเริ่ม คลิกไอคอน record2context แล้วกด **Start recording** (หรือ `Alt+Shift+R`)
2. ใช้งานตามปกติ จะมีแถบเล็ก ๆ ด้านล่างของหน้า
   - **Screenshot** (`Alt+Shift+S`): เก็บภาพหน้าจอ ณ ตอนนั้น วิดีโอหยุดชั่วคราว วาดกรอบ ลูกศร หรือเส้นบนภาพ และพิมพ์โน้ตได้ (ภาษาไทยได้) แล้วกด Continue จะบันทึกไว้เพื่อเอาแค่ภาพหน้าจอก็ได้ ได้ network และ log ของหน้านั้นติดมาด้วย
   - **Stop** (`Alt+Shift+R`): จบการบันทึก ไฟล์ถูกบันทึกเองโดยไม่มีหน้าต่างถาม

   คีย์ลัดแสดงอยู่บนปุ่มในแถบ และในหน้าต่าง popup ถ้าเปลี่ยนหรือลบคีย์ที่ `chrome://extensions/shortcuts` จะแสดงตามที่ตั้งไว้
3. คลิกไอคอนอีกครั้ง แล้วเลือก
   - **Copy for my AI**: ข้อความสั้น ๆ ที่ชี้ไปยังโฟลเดอร์บันทึก วางให้ AI ที่อ่านไฟล์ในเครื่องได้ แล้วพิมพ์คำถามของคุณต่อ
   - **Copy portable context**: สรุปการบันทึกเป็นข้อความ สำหรับ AI ที่อ่านไฟล์ในเครื่องไม่ได้ หรือสำหรับแปะใน issue
   - **Show folder**: เปิดโฟลเดอร์บันทึกใน Finder
   - **All recordings**: ดูทุกการบันทึก เล่นวิดีโอพร้อม timeline ลบ หรือบันทึกลงโฟลเดอร์

## ในโฟลเดอร์บันทึกมีอะไร

```
<โฟลเดอร์บันทึก>/2026-10-28_153000_example-com/
  2026-10-28_153000_example-com.webm   วิดีโอ
  screenshot-01.png                    ภาพจากการกด Screenshot ครั้งที่ 1 (มีสิ่งที่วาดถ้าวาดไว้)
  details/
    report.json                        log ทั้งหมด เรียงตามเวลาในวิดีโอ
    AI-README.md                       คำอธิบายรูปแบบไฟล์สำหรับ AI
    context.md                         สรุปเดียวกับ Copy portable context
    screenshots/                       ภาพ Screenshot ต้นฉบับที่ยังไม่ได้วาด
    private-do-not-share/              ข้อมูลดิบ ห้ามแชร์
      storage/                         ค่า localStorage และ sessionStorage แบบไม่ปิดบัง
      bodies/                          เนื้อหา request และ response ของ fetch/XHR
```

- **ชั้นนอกสุด** คือไฟล์ที่แนบลง issue ได้เลย: วิดีโอและภาพที่คุณกดตอนบันทึก
- **`details/`** คือข้อมูลสำหรับ AI และนักพัฒนา
- **`details/private-do-not-share/`** มีข้อมูลที่อาจเป็นความลับของหน้าเว็บ ใช้กับ AI ในเครื่องของคุณเองเท่านั้น ข้อมูลในนี้ไม่เคยถูกใส่ใน `report.json`, `context.md` หรือ Copy portable context

## ความเป็นส่วนตัว

- ช่องรหัสผ่าน อีเมล และช่องที่ดูเป็นข้อมูลลับ ถูกบันทึกเป็น `[MASKED]` อีเมลในส่วนอื่นเป็น `[EMAIL]` ค่าใน URL ที่ดูเป็นความลับเป็น `[REDACTED]`
- ค่าใน storage ที่อยู่ใน `report.json` ถูกปิดบังตามชื่อ key (token, auth, session, password, pass, key ...) รวมถึง JSON ที่ซ้อนอยู่ข้างใน และตามรูปแบบค่า (JWT, key ที่ขึ้นต้นแบบ AKIA/sk-/ghp_ เป็นต้น, สตริง 16 ตัวขึ้นไปที่มีทั้งตัวอักษรและตัวเลขและไม่มีช่องว่าง เช่น UUID, อีเมล) ส่วนคุกกี้เก็บแค่ชื่อ ไม่เคยอ่านค่า
- กฎเดียวกันใช้กับข้อความ error ใน console, ชื่อปุ่ม/ป้าย และค่าที่พิมพ์ในช่องธรรมดา ส่วน path อย่าง `/projects/123/edit` ยังอ่านได้
- โน้ตที่คุณพิมพ์เองใน Screenshot ถูกเก็บตามที่พิมพ์
- วิดีโอบันทึกทุกอย่างที่อยู่บนจอ รวมถึงสิ่งที่พิมพ์
